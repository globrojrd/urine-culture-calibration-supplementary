# Verified analysis outputs

These outputs were regenerated on 20 November 2026 from the recovered original study artifacts. `reproduction_validation.json` compares them with saved historical outputs. All values describe the same retrospective image-level experiment; they are not results from a new cohort or retraining.

| Files | Meaning |
|---|---|
| `paired_exact_tests_holm.csv` | Six exact paired comparisons; Holm separately for Accuracy and TNRR. |
| `paired_bootstrap_metric_differences.csv` | All 30 marginal metric-difference intervals from 3,000 paired resamples. |
| `single_policy_bootstrap_summary.csv` | Separate original 2,000-resample procedure; degenerate NPV interval retained with its interpretation caveat. |
| `false_negative_analysis.csv` | Distinct denominators and exact one-sided bounds. |
| `policy_operating_summary.csv`, confusion/release tables | Original frozen-policy operating and classification outcomes. |
| `development_by_seed.csv`, `development_ranking.csv`, `final_test_by_seed.csv` | Refit factorial outputs; small numeric differences from historical fitted probabilities are documented. |
| `sensitivity_summary.csv`, `sensitivity_rankings.csv`, `ensemble_threshold_sensitivity_100_repartitions.csv` | Repeated development-only calibration/threshold analysis; all historical winners/ranks and operating counts agree. |
| `verified_split_counts.csv`, `verified_27_training_runs.csv`, `recomputed_training_duration_minutes.csv` | Audits of saved partitions, histories and recorded timing; not new training measurements. |
| `training_validation_curves.png` | Curves regenerated from the three actual selected-model histories. |
| `serialization_boundary_audit.json` | Original CSV-parser boundary effect in 15 development conditions; final evaluation is unaffected. |

The 90,000 individual paired-bootstrap differences are regenerated by `scripts/compare_policies.py` or `scripts/verify_reproduction.py`; only their summaries are stored here to keep the repository compact. Saved original fitted parameters are in `data/frozen_ensemble.json`. Statistical reanalysis should use the original seven frozen-policy CSVs in `data/review/`; do not substitute refitted probability tables when checking historical numerical intervals.
