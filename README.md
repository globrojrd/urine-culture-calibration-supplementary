# Supplementary Material: A Factorial Evaluation of Calibration Methods for Selective Automated Urine Culture Screening

This repository contains the supplementary material associated with the manuscript:

"A Factorial Evaluation of Calibration Methods for Selective Automated Urine Culture Screening"

## Contents

The supplementary material includes:

- Reliability analysis of the operational ensemble.
- Computational characteristics of evaluated architectures.
- Seed-specific operating policies.
- Risk–coverage analysis.
- Multiclass predictions and operational release decisions.
- Release counts by probability condition.
